# MSC PRPCEM Documentation Portal

Official internal documentation repository and operational playbook for **Microsoft Student Club at P. R. Pote (Patil) College of Engineering and Management, Amravati** (`docs.mscprpcem.tech`).

---

## ⚡ 100% Markdown Driven

All club documentation, SOPs, checklists, and guidelines are stored as pure **Markdown (`.md`) files**. 

Club leads and contributors can update or add content directly on GitHub via standard pull requests or by clicking **"Edit this page on GitHub"** on any documentation page.

---

## 📁 Repository Directory Structure

```text
├── .vitepress/           # VitePress site configuration and custom theme
│   ├── config.mjs        # Search, navigation, and sidebar config
│   └── theme/            # Theme extension and CSS micro-animations
├── public/               # Static assets, SVG logos, and 3D illustrations
├── club/                 # Institutional governance, leadership, and charter
├── events/               # 6-phase event operational lifecycle and checklists
├── sops/                 # 14-point binding Standard Operating Procedures
├── technical/            # Azure cloud, Git workflow, and engineering baselines
├── project/              # Active project registry and system architecture
├── team/                 # Team charters (Technical, Operations, Docs)
├── policies/             # Binding club policies and code of conduct
├── tools/                # Interactive admin letter maker, budget, checklists
├── templates/            # Standard reusable document templates
├── reference/            # Campus emergency contacts and approved tools
└── archive/              # Verified past event archives and changelog
```

## 🚀 Local Development

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start the local documentation server:**
   ```bash
   npm run dev
   ```
   Open `http://localhost:5174` in your browser.

3. **Build production bundle:**
   ```bash
   npm run build
   ```

4. **Preview production build:**
   ```bash
   npm run preview
   ```

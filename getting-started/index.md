# Documentation Portal Overview

The MSC PRPCEM Documentation Website (`docs.mscprpcem.tech`) is the single authoritative knowledge repository for the Microsoft Student Club at P. R. Pote (Patil) College of Engineering and Management, Amravati.

## Purpose and Scope

The exclusive purpose of this portal is to document:
- How technical systems and software projects are engineered, deployed, and maintained.
- Standard Operating Procedures (SOPs) for administrative permissions, venue bookings, and events.
- Core team domain charters, responsibilities, and key performance indicators (KPIs).
- Institutional policies, data privacy guidelines, and code quality standards.
- Reusable templates and verified campus reference directories.

::: tip Authorized Club Members Only
This website is intended for authorized club members, leads, and student developers. It is not an open public blog or general learning portal.
:::

## Explicit Non-Goals

To preserve operational clarity, this repository strictly adheres to the following boundaries:
1. **No External Course Links:** We do not host generic online tutorial links or syllabus summaries.
2. **No Event Ticketing:** External attendee registrations and ticketing are managed via dedicated registration platforms.
3. **No Secret Storage:** Plaintext API keys, passwords, database credentials, or Azure cloud tokens are strictly prohibited.
4. **No Speculative Information:** Content must reflect verified club processes and approved policies.

## Single Canonical Location

Every procedure, standard, and project specification has **exactly one canonical location**. Duplicate documents are forbidden; cross-references are maintained via markdown links.

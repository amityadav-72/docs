# Document Ownership and Responsibilities

Every document in this repository has an assigned maintainer:
- **President:** Club Governance, Institutional Relations, and Succession.
- **Technical Lead:** Development baselines, Git workflows, and Azure cloud standards.
- **Event Operations Lead:** Event planning, hall requisitions, and D-day runbooks.
- **Documentation Lead:** Editorial integrity, formatting standards, and portal maintenance.

Owners are required to audit documents every 90–180 days to ensure commands and college procedures remain accurate.

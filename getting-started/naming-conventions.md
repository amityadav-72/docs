# Documentation Categories & Naming Conventions

## Document ID Standard

Every canonical document is assigned a unique identifier:
```
[CATEGORY_PREFIX]-[NUMBER]
```

### Official Prefixes:
- `GS`: Getting Started
- `CD`: Club Documentation
- `TD`: Team Documentation
- `TECH`: Technical Documentation
- `PRJ`: Project Documentation
- `EVT`: Event Documentation
- `SOP`: Standard Operating Procedures
- `POL`: Policies and Guidelines
- `TMPL`: Templates and Standards
- `REF`: Reference Documentation
- `ARC`: Archive and Revision History

## Markdown File Naming Rules
- **Format:** Strictly lowercase kebab-case (`workshop-planning.md`).
- **No Special Characters:** Use only hyphens and alphanumeric characters.
- **Root Placement:** Files are saved inside their respective category folders (`/sops/`, `/policies/`, `/club/`).

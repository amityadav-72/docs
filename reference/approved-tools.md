# Approved Tools & Software Index

## Development Tools
- **Code Editor:** Visual Studio Code (Official Microsoft build).
- **Version Control:** Git & GitHub CLI (`gh`).
- **Containerization:** Docker Desktop.
- **API Testing:** Postman, Thunder Client.
- **Terminal Shell:** PowerShell (Windows), Bash / Zsh (Linux/macOS).

## Cloud & Production Hosting
- **Primary Cloud Provider:** Microsoft Azure (App Service, Functions, Blob, Entra ID).
- **DNS & CDN:** Cloudflare.
- **CI/CD Automation:** GitHub Actions.

## Creative Tools
- **UI/UX Design:** Figma.
- **Flyers & Posters:** Canva Pro (Education/Team), Adobe Illustrator.
- **Documentation Platform:** VitePress, Markdown.

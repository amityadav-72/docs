## Developer Toolchain Baseline
All contributors must maintain the following minimum toolchains:
- **Node.js:** `v20.x LTS` or later.
- **npm:** `v10.x` or later.
- **Python:** `v3.11.x` or later.
- **Git:** `v2.40+` with SSH key authentication.
- **Editor:** Visual Studio Code with ESLint and Prettier extensions.

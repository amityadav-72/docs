# Permanent Partnership Directory

Beyond financial sponsorships, **.NET Conf Amravati** relies on strategic collaborations with technology user groups, university student clubs, regional developer networks, and open-source foundations. This directory preserves the permanent institutional history of these non-financial partnerships.

---

## 1. Collaboration Tiers & Governance

To maintain clarity, all non-financial relationships are categorized into three distinct operational tiers:

```
┌────────────────────────────────────────────────────────────────────────┐
│                        PARTNERSHIP TIERS                               │
├────────────────────┬────────────────────┬──────────────────────────────┤
│ Formal Strategic   │ Community Alliance │ One-Time Technical           │
│ Partner            │ (Ongoing)          │ Contributor                  │
│ Governed by signed │ Mutual promotion,  │ Single-edition session       │
│ institutional MoU; │ shared call for    │ delivery or localized        │
│ recurring annual   │ speakers, joint    │ workshop without formal      │
│ co-branding.       │ study jams.        │ multi-year commitment.       │
└────────────────────┴────────────────────┴──────────────────────────────┘
```

## 3. Partnership Management SOPs

When establishing or renewing a non-financial partnership:
1. **Clarify Resource Commitments:** Ensure mutual promotional obligations and timelines are clearly written.
2. **Designate a Student Relationship Owner:** Each partner organization must have a dedicated student point of contact to avoid miscommunication.
3. **Conduct Post-Event Debriefs:** Send formal appreciation letters and invite partner community leads to join the post-conference feedback review.

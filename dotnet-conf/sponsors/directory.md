## 4. Partnership Governance & Code of Conduct

1. **Student Value First:** In-kind sponsorships must deliver direct technical value to student delegates (e.g. software licenses, cloud tools, domain names, technical literature).
2. **Transparent Institutional Auditing:** Every voucher, license, or grant is accounted for in the annual financial and operational review.
3. **Data Privacy Protection:** Attendee personal data (phone numbers, private emails) is never sold or shared with any external third party.

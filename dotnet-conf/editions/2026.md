## 1. Edition Overview

- **Official Title:** .NET Conf Amravati 2026
- **Edition Tag:** `DNCA-2026`
- **Scheduled Date:** March 2026 (Tentative Saturday window)
- **Target Duration:** 08:30 AM – 06:30 PM IST (Full Day)
- **Venue:** PRPCEM Convention Center, Main Auditorium & Tech Arena Complexes
- **Event Format:** In-Person Triple-Track Conference with Parallel Hackathon Demo Arena
- **Working Theme:** *Intelligent Cloud Applications with .NET 10 & Semantic Kernel*
- **Convening Body:** Microsoft Student Club PRPCEM in association with Department of CSE, IT & AI-DS
- **Current Preparation Status:** <span class="badge badge-info">Phase 2: Outreach & Funding Active</span>
- **Core Objectives:**
  1. Showcase the next frontier of Microsoft .NET: .NET 10 previews, C# 14 capabilities, and deep AI agentic workflows via Semantic Kernel.
  2. Expand to a Triple-Track format (Track 1: Cloud Architecture; Track 2: AI & Intelligent Agents; Track 3: Modern Web & Mobile Labs).
  3. Host 600+ student and professional engineers from across Maharashtra, establishing the largest community tech gathering in Amravati history.

## 3. Speakers & Sessions Pipeline

The Technical Committee is curating 12 sessions across three dedicated tracks:

### Track 1: Cloud Native & Distributed Systems (Auditorium 1)
- *Keynote:* Evolution of .NET Towards Unified Cloud Native Runtimes
- *Session 1:* High-Speed Event-Driven Architecture with Azure Service Bus & C#
- *Session 2:* Resilient Microservices with .NET Aspire & Container Orchestration
- *Session 3:* Production Observability: OpenTelemetry, Distributed Metrics & Grafana

### Track 2: Enterprise AI & Intelligent Workflows (Auditorium 2)
- *Session 1:* Building Multi-Agent Systems using Semantic Kernel in .NET
- *Session 2:* Local LLM Inference with ONNX Runtime & C#
- *Session 3:* Azure OpenAI Integration Patterns: Retrieval-Augmented Generation (RAG)
- *Session 4:* Securing AI Microservices against Prompt Injection & Data Leakage

### Track 3: Modern Development & Interactive Labs (Lab Complex A)
- *Session 1:* Full-Stack Web Development with Blazor WebAssembly & Server Rendering
- *Session 2:* Cross-Platform Desktop & Mobile Engineering with .NET MAUI
- *Session 3:* Hands-on Guided Lab: Deploying First Semantic Agent in 60 Minutes
- *Session 4:* Open-Source Lightning Talks & Student Project Demos

## 3. Technical Setup & AV Requirements Specification

To prevent any technical failures during live demonstrations, all speakers must review these audio-visual standards:

| Technical Element | Auditorium Specification | Speaker Recommendation |
| :--- | :--- | :--- |
| **Display Resolution** | Dual 4K Laser Projection (16:9 Aspect Ratio) | Set IDE and slide presentation resolution to 1920x1080 (1080p). |
| **Video Input** | HDMI & USB-C DisplayPort available on stage | Bring standard USB-C to HDMI dongle if using MacBook or ultrabook. |
| **Audio Setup** | Shure Wireless Lapel Mic + Handheld Q&A Mics | Lapel mic fitted 10 minutes prior to stage entry. |
| **Internet Access** | Dedicated 300 Mbps Leased Line (SSID: `DNCA-SPEAKER-STAGE`) | Hardwired Ethernet cable available directly on podium table. |
| **IDE Text Sizing** | Large hall visibility (Seating depth: 35 meters) | Set VS Code / Visual Studio font size to minimum 18pt–20pt. |
| **Terminal Contrast** | High-contrast theme required | Use dark background with vibrant text or crisp light mode. |

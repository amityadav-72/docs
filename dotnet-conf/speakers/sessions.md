# Technical Session Archive

This archive documents every technical lecture, keynote address, and interactive workshop delivered at **.NET Conf Amravati**. It links each session to its slides, code repositories, and recorded video broadcasts in the [Resource Archive](/dotnet-conf/archive/).

---

## 1. 2025 Edition Technical Sessions (Dual-Track)

### Track A: Enterprise Architecture & Modern .NET (Main Auditorium)

#### Session 25-A1: Keynote: Enterprise Scalability with .NET 9 & Cloud-Native Runtimes
- **Speaker:** Aniket Deshpande (Principal Cloud Solutions Architect & Microsoft MVP)
- **Track & Time:** Track A | 10:15 AM – 11:30 AM
- **Abstract:** An exhaustive architectural exploration of .NET 9 performance enhancements, Server Garbage Collection (Server GC) optimizations, Native AOT improvements in ASP.NET Core, and C# 13 language features including enhanced params collections and new lock objects.
- **Key Takeaways:** Real-time benchmark comparisons between .NET 8 and .NET 9 runtimes; zero-allocation memory patterns for high-frequency transactions.
- **Resources:** [Download Slides (PDF)](/dotnet-conf/archive/) | [GitHub Demo Repository](https://github.com/mscprpcem/docs)

#### Session 25-A2: High-Throughput Microservices with ASP.NET Core & gRPC
- **Speaker:** Saurabh N. Joshi (Tech Lead, Apex Enterprise Software)
- **Track & Time:** Track A | 11:45 AM – 12:45 PM
- **Abstract:** How to build ultra-low-latency inter-service communication using Protocol Buffers and gRPC over HTTP/2. Covers service contracts, bidirectional streaming, retry policies with Polly, and distributed tracing.
- **Resources:** [Download Slides (PDF)](/dotnet-conf/archive/) | [Sample Solution (.NET 9)](https://github.com/mscprpcem/docs)

#### Session 25-A3: Advanced Full-Stack Blazor Architecture in .NET 9
- **Speaker:** Regional Web Practice Lead
- **Track & Time:** Track A | 02:00 PM – 03:00 PM
- **Abstract:** In-depth demonstration of unified web development in .NET 9. Covers Interactive Server, Interactive WebAssembly, and Static Server Rendering (SSR) in a single solution without JavaScript build pipelines.
- **Resources:** [Download Slides (PDF)](/dotnet-conf/archive/) | [Blazor Source Code](https://github.com/mscprpcem/docs)

#### Session 25-A4: Production Resilience & Observability with OpenTelemetry
- **Speaker:** SRE & Cloud Architect
- **Track & Time:** Track A | 03:15 PM – 04:15 PM
- **Abstract:** Instrumenting .NET microservices with OpenTelemetry standards. Emitting structured metrics, distributed traces, and log telemetry into Prometheus, Grafana, and Azure Monitor.
- **Resources:** [Download Slides (PDF)](/dotnet-conf/archive/) | [Telemetry Dashboards](https://github.com/mscprpcem/docs)

### Track B: Cloud, DevOps & AI Integration (Seminar Hall A)

#### Session 25-B1: Generative AI with C# & Microsoft Semantic Kernel
- **Speaker:** Priya R. Kulkarni (Senior AI Solutions Architect)
- **Track & Time:** Track B | 10:15 AM – 11:30 AM
- **Abstract:** Connecting .NET applications to Large Language Models (LLMs) using Semantic Kernel. Implementing plugins, memory stores, kernel functions, and Retrieval-Augmented Generation (RAG) pipelines in C#.
- **Resources:** [Download Slides (PDF)](/dotnet-conf/archive/) | [Jupyter Notebooks & C# Code](https://github.com/mscprpcem/docs)

#### Session 25-B2: Containerized .NET on Azure Kubernetes Service (AKS)
- **Speaker:** Cloud Infrastructure Specialist
- **Track & Time:** Track B | 11:45 AM – 12:45 PM
- **Abstract:** Containerizing ASP.NET applications with Docker distroless base images, deploying to AKS with Helm, configuring horizontal pod autoscaling (HPA), and managing secrets via Azure Key Vault CSI driver.
- **Resources:** [Download Slides (PDF)](/dotnet-conf/archive/) | [Kubernetes Manifests](https://github.com/mscprpcem/docs)

#### Session 25-B3: Modern Identity & Security with Microsoft Entra ID
- **Speaker:** Meera Nair (Cloud Security Architect)
- **Track & Time:** Track B | 02:00 PM – 03:00 PM
- **Abstract:** Implementing robust authentication and authorization in ASP.NET Core APIs using Microsoft Entra ID (formerly Azure AD), JWT validation, role-based access control (RBAC), and token caching.
- **Resources:** [Download Slides (PDF)](/dotnet-conf/archive/) | [Security Code Samples](https://github.com/mscprpcem/docs)

#### Session 25-B4: Interactive Guided Lab: Building an End-to-End Microservice
- **Speaker:** MSC PRPCEM Senior Technical Fellows
- **Track & Time:** Track B | 03:15 PM – 04:45 PM
- **Abstract:** A 90-minute live, hands-on guided lab for 80 student engineers. Attendees wrote, containerized, and deployed a functional RESTful API connected to PostgreSQL using EF Core 9.
- **Resources:** [Step-by-Step Lab Guide (Markdown)](/dotnet-conf/archive/) | [Starter Codebase](https://github.com/mscprpcem/docs)

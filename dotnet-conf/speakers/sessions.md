This archive documents every technical lecture, keynote address, and interactive workshop delivered at **.NET Conf Amravati**. It links each session to its slides, code repositories, and recorded video broadcasts in the [Resource Archive](/dotnet-conf/archive/).

## 1. 2025 Edition Technical Sessions

The 2025 edition featured 3 distinguished industry speakers delivering in-depth technical sessions, along with a guided hands-on student lab and fireside panel:

### Session 25-01: Keynote: Upcoming .NET 10 & Enterprise Cloud-Native Architecture
- **Speaker:** Aniket Deshpande (Principal Cloud Solutions Architect & Microsoft MVP)
- **Time & Track:** Morning Keynote | 10:00 AM – 11:30 AM
- **Abstract:** An exhaustive architectural exploration previewing upcoming .NET 10 capabilities, .NET 9 enterprise performance benchmarks, Server Garbage Collection (Server GC) optimizations, Native AOT improvements, and cloud-native scaling patterns.
- **Key Takeaways:** Real-time benchmark comparisons between .NET runtimes; zero-allocation memory patterns for high-frequency cloud transactions.
- **Resources:** [Download Slides (PDF)](/dotnet-conf/archive/) | [GitHub Demo Repository](https://github.com/mscprpcem/docs)

### Session 25-02: Generative AI with C#, Semantic Kernel & Power Platform
- **Speaker:** Priya R. Kulkarni (Senior AI Solutions Architect & Microsoft MVP)
- **Time & Track:** Midday Session | 11:45 AM – 01:00 PM
- **Abstract:** Connecting .NET and enterprise workflows to Large Language Models (LLMs) using Microsoft Semantic Kernel. Implementing plugins, memory stores, kernel functions, and integrating AI automations with Power Platform.
- **Key Takeaways:** Hands-on integration of Azure OpenAI with native C# APIs and practical AI agent workflows.
- **Resources:** [Download Slides (PDF)](/dotnet-conf/archive/) | [Jupyter Notebooks & C# Code](https://github.com/mscprpcem/docs)

### Session 25-03: High-Throughput Microservices with ASP.NET Core, gRPC & Azure DevOps
- **Speaker:** Saurabh N. Joshi (Cloud Architect & Microsoft MVP)
- **Time & Track:** Afternoon Session | 02:00 PM – 03:15 PM
- **Abstract:** How to build ultra-low-latency inter-service communication using Protocol Buffers and gRPC over HTTP/2, coupled with automated CI/CD deployment pipelines using Azure DevOps and GitHub Actions.
- **Key Takeaways:** Building enterprise-grade, high-performance distributed systems in modern .NET.
- **Resources:** [Download Slides (PDF)](/dotnet-conf/archive/) | [Sample Solution (.NET 9)](https://github.com/mscprpcem/docs)

### Interactive Guided Lab & Community Open Mic
- **Conducted by:** MSC PRPCEM Senior Technical Team
- **Time:** 03:30 PM – 05:00 PM
- **Abstract:** Hands-on containerized development workshop and fireside career discussion for student delegates covering GitHub Codespaces, Azure Container Apps, and Power Platform connectors.
- **Resources:** [Step-by-Step Lab Guide (Markdown)](/dotnet-conf/archive/) | [Starter Codebase](https://github.com/mscprpcem/docs)

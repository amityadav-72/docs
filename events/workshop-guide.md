# 70% Hands-on Workshop Guide

## Pedagogical Requirements
Every technical workshop must strictly enforce:
- **Maximum 30% Theory:** High-level conceptual overview and architectural context.
- **Minimum 70% Hands-on Execution:** Students write, compile, and run code in the lab.
- **Starter Repositories:** Provide pre-built starter repositories on `github.com/mscprpcem` with clear step-by-step lab instructions so students do not get stuck on boilerplate configuration.
- **Aisle Mentors:** Technical team volunteers roam aisles to resolve student syntax bugs and installation issues immediately.

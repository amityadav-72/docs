# Post-Event Reporting (PER) Procedure

## The 72-Hour Mandate
Within 72 hours following any event:
1. Operations Lead compiles the 4-page Post-Event Report using [TMPL-18](/templates/post-event-report).
2. Attach verified attendance lists and feedback metrics.
3. Attach 6 high-resolution event photographs.
4. Obtain signatures from Event Lead, President, and Faculty Coordinator.
5. Submit one signed hardcopy to the Principal's office and one to the HoD.

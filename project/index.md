# Project Documentation Standards

Every software application maintained by MSC PRPCEM must contain:
1. **README.md:** Executive overview, runtime prerequisites, setup commands, environment keys.
2. **Architecture Specification:** Component boundaries, database ER diagrams, API contracts.
3. **Deployment Runbook:** Step-by-step production release instructions and rollback procedures.
4. **Maintenance Schedule:** Dependency update cadence and maintainer transition plan.
